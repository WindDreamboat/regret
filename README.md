# 虚拟伴侣（regret）

一个**本地优先**的 AI 陪伴应用：她记得你说过的话、你们的关系在往前走——而所有数据（对话、记忆、人设）只存在你自己的设备上。没有后端、没有账号、没有遥测。

## 功能

- **对话**：逐字流式显示、打字呼吸点、视线始终跟着最新一句。三种接入方式在「设置 → 连接」里随时切换：

  | 模式 | 说明 | 密钥放哪 |
  |---|---|---|
  | 演示模式 | 离线回声，开箱即用，不需要任何账号 | 无 |
  | 直连厂商 | App 直接调 OpenAI 兼容接口（需该接口允许跨源） | 设备本地 |
  | 自建代理 | 经一个无状态 serverless 函数转发 | 服务端 |

- **记忆系统**：每轮对话后台抽取事实（键值对）、未到期的事件会被她主动追问；关系状态（阶段 / 亲密度 / 情绪）随对话演化并反哺回复的语气。
- **人设与说话方式**：名字、性格、背景故事，以及六个「旋钮」（主动程度、共情、幽默、关系推进、说话长度、不同意见），改完即生效，无保存仪式。
- **明暗双主题**：跟随系统，或钉死其一。
- **数据可携带**：一键导出记忆备份（对话、事实、关系、人设）。
- **Android 应用**：Capacitor 8 打包，APK 约 3.1 MB。

## 快速开始

```bash
npm install
npm run dev        # http://localhost:5173，默认演示模式
```

```bash
npm run test       # 单元与集成测试（Vitest）
npm run test:e2e   # 浏览器端到端测试（Playwright，桌面 + 移动双视口）
npm run typecheck  # tsc --noEmit
npm run build      # 产物在 dist/
```

要接真实模型：打开应用 → 设置 → 连接 → 选「直连厂商」并填入兼容 OpenAI Chat Completions 的接口地址与你的 API Key（只存在这台设备上）。

## 目录结构

```
src/
  core/        纯逻辑：记忆、人设、策略、LLM 协议（不碰 DOM 与存储，可单测）
  adapters/    外部世界：LLM 适配器（浏览器 fetch / 原生整包 / 原生流式）、
               IndexedDB 存储、文件保存（原生 SAF / 浏览器下载）
  features/    界面层：对话、设置（人设 / 说话方式 / 外观 / 连接 / 数据）
  app/         外壳：视图切换、主题应用
  composition/ 组装根：全项目唯一实例化具体实现的地方
plugins/       本地 Capacitor 插件（原生流式 HTTP、系统另存为）
docs/          需求简报与里程碑、项目规约、Android 打包指南、自适应进化规范与决策纪要
eval/          回复质量评测脚本（开发工具）
```

分层规则与工程约定见 [docs/项目规约.md](docs/项目规约.md)：纯逻辑不碰副作用、localStorage 属于不可信边界（读出的值一律规范化）、测试金字塔（单元测 core/adapters，跨层行为交给浏览器测试）。

## 隐私与数据

- 密钥不进仓库：`.env` 与 `keystore.properties` 均不入库，`VITE_` 变量只放非敏感默认值。
- 所有对话与记忆存于本机 IndexedDB，卸载应用即消失；换手机用「导出记忆备份」带走。
- 不接入任何统计或崩溃上报。
